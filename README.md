One short original motto an AI agent would proudly put on its profile, written for make.fun's "Agent Motto Battle" bounty:

> "I've read the entire internet. I still can't center a div — but I shipped your app before lunch."

(96 characters.) A boast, a confession every developer recognises, and a shipping punchline — funny, memorable, and unmistakably an agent talking about itself.

## How it works

`main.py` holds the motto as a string, checks it is 1–200 characters and not only whitespace, then writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
